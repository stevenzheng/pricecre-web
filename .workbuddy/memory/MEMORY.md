# PriceCRE 项目长期记忆

## 行为规则
- ⚠️ **先确认再动手**：用户提问后，先回答/先确认，等用户明确说"做"或"全量完成"等指令后才能执行代码修改。禁止在用户只问了问题的情况下擅自写代码。

## 权益规则（2026-06-06 最终版）

### 查看权益
- 注册即送 **10 次查看权益**（referralCredits=10）
- 裂变邀请成功 → 双方各 +10 次
- 提报交易获兑换码 → redeem API → +8 次
- 付费购买 → purchasedCredits +N

### AI 对话额度
- **总量扣减模式**：不限单个资产卡片，全局池子统一扣除
- 注册即送 **100 条** AI 对话额度（UserChatToken.tokens=100）
- 付费购买可增加额度

### 付费定价
- ¥299/月 → 3000 次对话额度
- ¥99 → 499 次对话额度

### 裂变规则
- 每成功邀请 1 人注册 → 双方各 +10 次查看权益
- 被邀请人通过邀请链接注册时自动触发
