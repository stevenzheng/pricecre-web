## 1. 项目概述

**PriceCRE** 是商业地产量化精算资产终端。覆盖写字楼、商业零售、产业园三大赛道，提供18维47项资产精算指标。支持双主题(明/暗)、中英双语、地图定位、社交裂变增长飞轮、AI智能分析。

**域名**: https://pricecre.com
**版本**: v4.1.0

## 4. 数据模型

### 4.1 资产模型 (CommercialProperty)

| 字段 | 类型 | 说明 |
|------|------|------|
| projectName | String | 项目名称 |
| city | String | 城市 |
| district | String | 区 |

### 4.2 47项动态指标 (DynamicIndicators)

| 分类 | 指标 |
|------|------|
| 租金流 | 面价、净有效租金 |
| 运营 | 净吸纳量、续租调升率、空间利用、收缴率 |
| 商业 | 坪效、租售比、客单价、掉铺率、首店占比、开闭店比 |
| 产业园 | 电产比、亩均税收、车位配比 |
| 投融资 | CapRate、售租比、WALE、租户留存、LTV、债务收益、现金回报、IRR、大宗单价 |
| 市场 | 商圈空置、企业迁入、总部集聚、政策级数、收益利差、热度指数、负面声量 |
| ESG | LEED/BREEAM/WELL 认证 |

## 5. 交互规范

- 移动端禁止缩放：`maximumScale=1, userScalable=false`
- 手机字号基准：`font-size: 120%`（19.2px）
- 弹窗：居中 Modal 方框，必须手动关闭
- 提示：Toast 底部滑入，2.5s 消失
- 额度不足时点击锁定的指标格子弹出 Modal 提示

## 6. AI 精算分析 (v4.1.0 新增)

### 6.1 入口
- 资产卡片展开后、底部操作栏显示「AI 分析」按钮（仅解锁状态可见）
- 按钮样式：紫蓝渐变背景 + 白色文字 + 微光阴影，hover 轻微放大

### 6.2 分析流程
1. 点击按钮 → 弹出 AI 分析 Modal
2. 展示加载动画（紫色旋转圆环 + "AI 正在分析 N 项精算指标..."）
3. 1.8s 后展示分析结果

### 6.3 分析内容
| 模块 | 说明 |
|------|------|
| 综合评分 | 0-100分圆形仪表盘，75+绿色/50-74蓝色/50以下红色 |
| 利好因素 | 基于指标数据自动生成的积极信号列表 |
| 风险提示 | 基于指标数据自动生成的潜在风险列表 |
| 综合分析 | 一段总结性评语，含评分+投资建议方向 |

### 6.4 评分逻辑
基于实时指标数据（资本化率、商圈空置、利润率、热度指数、企业迁入、租户留存、收缴率、ESG、负面声量、收益利差等）加权计算。

### 6.5 技术实现
- 前端：React 组件 AIAnalysis.tsx，通过 CustomEvent 驱动
- 当前为规则引擎模拟分析；后续可接入 AI API（GPT/Claude）实现深度分析
- AI API Token 预留配置接口

### 6.6 免责声明
Modal 底部标注："以上分析基于公开市场数据与 AI 精算模型生成，仅供参考，不构成投资建议。"
