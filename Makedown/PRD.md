# 产品需求文档 (PRD.md)
# 版本：v2.7.0 (终极杠杆与商圈人口红利穿透版)

## 1. 项目愿景与定位
基于已上线的 V1 版本布局作为底座，全量移植并深度进化业务逻辑，生产环境全量部署至顶级域名：`https://pricecre.com`。利用 Next.js 14 全栈强类型架构，在 Vercel 零配置运行。项目全站统一、强行对齐 **BitMart 新一代高频金融量化终端美学 (Neo-Financial Minimalism)**。系统以租金为主核心指标，以 18 维资产精算指标体系为次附属指标，全面承载写字楼（OFFICE）、大商业零售（SHOPS）以及产业园/物流园/研发厂房（INDUSTRIAL）三大主力赛道。通过打通高度灵活的元数据字段显隐管理群组，并引入双向迎新分池裂变增长飞轮，打造具备顶级投行价值穿透力与绝对安全防线的商业地产顶级量化精算资产终端。

## 2. 用户画像
- **高频商业地产经纪人**：追求极高的数据时效与资产对标效率。对视觉的量化高级感有挑剔的需求，通过分享高度透明的社交裂变推荐链接获取查看额度，是平台自传播的动力源泉。
- **大资产管理机构 / 基金投资者 / 投行精算师**：看重“融、投、管、退”全生命周期闭环。需要通过大宗交易对标价、LTV、Debt Yield、Cash-on-Cash、预测 IRR 等重资产硬核指标，精准研判资产底层造血能力与财务安全性。
- **企业选址负责人 / 品牌商网点规划师**：极度关注写字楼大客户迁入率、全生产供应链总部集聚度、城市首店率、核心地段开闭店动态漏斗比以及周边商圈 3 公里人口统计红利。
- **最高管理员（大老团队）**：拥有最高控制权，能零代码在后台增删改查字段，配置显隐与安全锁控，并实时掌控大盘裂变流向。

## 3. 全量 BitMart 金融级视觉颗粒度规范
### 3.1 Highlight 轻重 (Highlight Contrast)
- **文字 Highlight 规范**：全站文字严格遵循三级字重（Font Weight）与亮度对比。
  - *一级高亮*：大厦/园区案名、核心金额/租金数值、已解锁的量化精算财务核心。统一采用 `text-zinc-50`，字重必须为 `font-bold` (700)。
  - *二级中亮*：区域商圈、空间类型、数据来源。采用 `text-zinc-300`，字重为 `font-medium` (500)。
  - *三级低亮（辅助文字）*：指标英文简称（如 Cap Rate, WALE, LTV, IRR）、更新时间、免责小字。采用暗淡的 `text-zinc-400`，字重为 `font-normal` (400)。
- **色彩 Highlight 规范**：上涨、已解锁、或知名企业净迁入率为正时，统一使用高明度极光绿（`#00C570`）；下跌、高危泡沫预警、品牌出现闭店撤铺潮、或未解锁锁定状态统一使用高饱和霓虹红（`#F24957`）。

### 3.2 信息层级 (Information Hierarchy)
- **主核心指标（租金流）**：挂牌面价高亮放大（正面免费曝光），净有效租金作为主核心拦截点（扣额/VIP 解锁）。
- **次附属指标（十八维精算）**：在卡片背面或展开面板中以紧凑的 3x4 或者 4x3 矩阵式通栏小字格（Grid）排列，在视觉面积上服从于主租金流。
- **一体化联动解锁逻辑**：用户消耗 1 次额度或 VIP 解锁该地产点位的“净有效租金”的一瞬间，对应的次附属指标面板在同一次异步请求中同步整体解锁展示。

### 3.3 层次结构与色块运用 (Elevation & Block-Color Layout)
- **底层大底**：黑曜石蓝黑（`#0B0E11`）。
- **中层卡片/面板**：无边框半透明毛玻璃微卡片（`bg-zinc-900/40 backdrop-blur-md`），外挂一层极细的灰色半透明微边框（`border border-zinc-800/40`）。
- **状态色块拦截**：当次附属指标被锁定时，该指标色块背景呈现微弱的半透明冷暗色，指标数值本身被替换为霓虹红锁定微章（`text-[#F24957]`）。

### 3.4 中英文排版机制
- 全站所有数字、百分比、金额、杠杆比率、时间、订单号统一强制单独包裹在 `font-mono` 下。在滚动浏览时，横向与纵向的字符点位永远完美对齐。
- 全站所有的中文标签、中文名称、区域商圈名、按钮描述文字，必须无条件强制使用 `font-sans`。

## 4. 核心功能规范
- **动态元数据驱动引擎**：超级管理员可一键配置该字段在“前台是否展示”与“是否属于拦截锁”。
- **裂变赠额分池与付费防塌陷红线**：新用户通过链接（`?ref=邀请码`）注册成功：推荐人账户即时获得 5 次可用额度；被推荐人立刻获得 +3 次初始可用额度。
- **历史累积上限控制**：单个账号通过邀请裂变可以获得的最高累积赠额上限被永久锁定为 100 次。
- **后台管理控制台分群组管理 (RBAC)**：后台严格划分三大管理群组：`ADMIN_DATA`（数据管理群组）、`ADMIN_FINANCE`（财务对账群组）以及 `SUPER_ADMIN`（最高管理员）。
