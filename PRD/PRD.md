# 项目名称：地产租金情报站 // 闭环量化终端 (ClosedLoopQuant)

## 1. 项目愿景
基于已上线的 V1 版本（https://sz4ai.com/rent/）作为核心活原型，全量继承并转化其业务逻辑、Apple 极简主义视觉风格、界面组件布局以及闭环量化文案。利用 Next.js 14 全栈架构从零重构，将其从一个静态样式页升级为具备自动化数据管线、全渠道登录、高阶数据锁、双支付订阅和“单次查看扣额”社交裂变机制的商业化全栈闭环量化终端。

## 2. 用户画像
- **高频商业地产经纪人**：对数据时效和对标效率极度敏感。由于平台提供的是“高置信度底牌数据”，用户天然接受“精准按次对标”或“高级会员订阅”的变现逻辑。可以通过分享推荐码到行业群裂变获取查看额度。
- **资产管理机构/企业选址负责人**：需要研判分化市场下的真实去化周期（DOM），是平台高级 VIP 会员的核心受众。

## 3. 核心功能列表 (商业化高级版)
### 3.1 V1 资产完整移植与组件化
- **视觉与文案百分百还原**：完全沿用 V1（sz4ai.com/rent/）的 Tailwind 响应式布局、流畅的 Dark Mode 深色切换、`JetBrains Mono` 数据对齐字体，以及所有专业的量化终端文案内容。
- **界面组件拆解**：将 V1 的顶部 LIVE 状态栏（含闪烁徽章）、大屏通告横幅、两栏式/三栏式租金对比卡片，全量改写为 Next.js 14 的 React 独立组件。

### 3.2 核心“单次查看”扣额逻辑与高级数据锁
- **按次精准消费锚点**：
  - *免费曝光层*：列表页和卡片正面，可以免费展示大厦案名、区域、全网挂牌面价（作为引流钩子）。
  - *高级锁定层*：卡片背面或深度数据区（净有效租金、真实空置率趋势、去化周期）默认被高级数据锁拦截。
  - *交互触发*：用户点击“解锁真实行情”按钮时，弹出二次确认弹窗。点击确认，调用后端 Server Action 进行原子扣额。
- **24小时复看免扣额机制（体验优化）**：
  - 引入查看日志缓存算法。24小时内，同一个用户查看同一个地产实况点位，只扣除第一次额度。缓存期内重复点进，直接放行，防止用户误刷或刷新导致愤怒。
- **服务端物理打码（安全防线）**：
  - 严禁采用前端 CSS 隐藏或高斯模糊。若判定当前用户无 VIP 且额度为 0，后端 Server Action 传向前端的 JSON 核心字段直接重写为 `null`，从物理层杜绝 F12 浏览器破解。

### 3.3 全渠道统一认证组件
- 基于 NextAuth.js 实现支持手机号（验证码/密码）、邮箱（验证码/密码）或微信扫码的统一极简登录组件，UI 样式必须完美融合 V1 苹果美学弹窗风格。

### 3.4 邀请推荐裂变机制 (Growth Loop)
- 每个注册用户自动拥有独立的推荐码和裂变 URL。
- **裂变防刷重奖算法**：当新用户通过该推荐链接注册成功，推荐人账户自动、即时奖励“**查看 5 次高价值租金数据额度**”，无上限累加。为防恶意注册，手机/邮箱注册需强制接入图形验证码风控。

### 3.5 微信/支付宝双支付变现
- 原生接入微信支付（H5/JSAPI/扫码）与支付宝（移动/PC），支持直接订购月卡、季卡、年卡（VIP 会员有效期内无限次查看），后端通过 Webhook 进行订单状态的异步确权回写。

## 4. 非功能性需求 (强类型与安全)
- **绝对的逻辑安全**：所有数据权限判定、额度扣减、订单状态变更，必须通过 Next.js **Server Actions** 在服务器端（Server-side）闭环完成。
- **极致加载性能**：得益于 Next.js 的 SSR（服务端渲染），继承 V1 的极速体验，首屏核心量化看板加载时间必须在 1.2 秒以内。
