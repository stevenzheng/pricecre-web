# 2025-06-05 — PriceCRE Admin Vercel 风格重构

## 环贸广场 pmOperatorTier 排查与修复
- **根因（前端不显示）**: PropertyCard 中 `pmOperatorTier` 被标记为 `isLocked: true`（付费字段），用户未解锁时该字段显示 `null` 而非 "新鸿基地产"
- **API 数据确认**: 生产数据库 `dynamicIndicators.pmOperatorTier = "新鸿基地产"` 已正确存储
- **修复**: 将 `isLocked` 改为 `false`（品牌名称属于基础属性，不应需要付费解锁）
- 环贸广场卡片无需解锁即可看到 品牌名称：新鸿基地产

## 字段管理页面空白问题
- **根因**: API 返回的 `FieldMetadata` 字段名 (`moduleType`/`fieldKey`/`fieldName`/`isDisplayed`) 与前端期望 (`propertyType`/`key`/`label`/`isActive`) 不匹配
- 数据库有数据时 filter 永远返回空，整个页面不渲染
- 修复: 在 useEffect 中添加 API 响应字段映射
- 顶部 Tab：写字楼 | 商业零售 | 产业园
- 每个业态拥有独立的字段列表和分类体系
- 写字楼：29项（核心/估值/租约/写字楼效率/运营/退出/物业品牌/资本债务/宏观/舆情/企业迁入）
- 商业零售：25项（核心/估值/租约/商业零售/品牌选址/零售生态/文化/运营/资本债务/宏观/舆情）
- 产业园：22项（核心/估值/产业园/运营/退出/物业品牌/资本债务/宏观/企业迁入）
- 每个业态字段配置独立存储（API moduleType 参数）
