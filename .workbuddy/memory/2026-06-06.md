# 2026-06-06 工作日志

## PriceCRE 电商后台体系搭建（本轮大改造）

### 1. Prisma Schema 升级
- **Order 模型增强**：新增 OrderStatus 枚举（0-5六种状态）、退款字段（refundReason/refundAmount/refundedAt）、取消/完成时间戳、note、updatedAt、items关联
- **新增 OrderItem 模型**：商品明细（productType/productName/quantity/unitPrice/totalPrice/creditsAdded）
- **UserChatToken 更新**：新增 totalUsed 字段追踪已用对话条数；默认值 tokens: 100
- **UserCredit 更新**：referralCredits 默认值从 3 改为 10（新用户 10 次查看权益）
- db push 成功同步 Supabase

### 2. 仪表盘新增三个核心指标
- 购买订单量（已支付+已完成）、本周新增订单、订单总额
- 已解锁资产卡片总数（UserViewLog 去重）
- 总对话量 + 本周对话量
- Stats API 新增字段：totalOrdersPaid, totalOrdersThisWeek, totalOrdersAmount, totalUnlockedAssets, totalConversations, conversationsThisWeek
- 配额池汇总：totalViewCredits, totalChatTokens
- 底部增长卡片调整为：已支付订单 / 订单总额 / AI对话

### 3. 订单管理完整电商体系（新建）
- **订单列表页** `/admin/orders`：分页、状态筛选、搜索（订单号/邮箱/交易号）
- **订单详情页** `/admin/orders/[id]`：订单信息、商品明细、退款/取消/完成操作
- **退款流程**：确认退款原因+金额 → 扣除用户对应额度（view_quota 扣 purcahsedCredits，chat_quota 扣 tokens）→ 写入审计日志
- **订单 API**：
  - GET `/api/admin/orders` — 列表（分页+筛选+搜索）
  - POST `/api/admin/orders` — 手动创建订单（管理员赠送）
  - GET `/api/admin/orders/[id]` — 订单详情
  - PUT `/api/admin/orders/[id]` — 订单状态操作（cancel/refund/complete/update_note）
- 侧边栏新增「订单管理」入口
