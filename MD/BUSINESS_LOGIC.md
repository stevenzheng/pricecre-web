# PriceCRE 前端交互与业务逻辑说明
## 版本：v3.0.0_MODULAR | 2026年6月4日

---

## 一、全局架构

### 1.1 页面结构
单页应用，四 Tab 底部导航：行情 / 地图 / 互享 / 我的

| Tab | 功能 | 路径 |
|-----|------|------|
| 行情 | 资产卡片列表 + 城市/业态筛选 | `/` |
| 地图 | Leaflet 灰度地图 + 城市资产定位 | `/` (tab=map) |
| 互享 | 租金数据提报表单 | `/` (tab=share) |
| 我的 | 登录/注册 + 分享转发 + 兑换 + 付费 | `/` (tab=profile) |

### 1.2 辅助页面
- `/terms` — 服务条款
- `/privacy` — 隐私政策
- `/contact` — 联系我们

## 二、行情页面

### 2.1 资产卡片 (PropertyCard)

**收起态**
- 显示类型标签、项目名、城市·区、挂牌租金面价
- 右上角三个市场波动指标（空置率/企业迁入/热度指数）
- 右下方显示锁定/解锁徽章 + 展开箭头
- 右侧空白区显示市场洞察文字（高热度商圈/低空置率等）
- **微信分享按钮**：标签右侧，点击生成微信卡片预览

**展开态**
- 净有效租金（需解锁）+ 附属精算指标 3x4 网格
- 47项指标按城市和业态动态显隐
- 点击指标名称 → 弹出对应指标的专业解释说明
- 点击锁定格子 → 自动触发解锁（有额度）/ 弹出额度不足提示
- 净有效租金右侧保留分享按钮

**解锁逻辑**
- 优先扣裂变赠额，归零后扣付费额
- 24小时同资产去重（CACHE_HIT 模式）
- 解锁后同步展示全部附属指标

## 三、地图页面

### 3.1 地图功能
- Leaflet 引擎 + CartoDB 灰度瓦片
- 城市 Tab 切换（上海/北京/深圳/苏州/成都）
- 资产按城市中心辐射分布
- 自定义标签标记：项目名 + ¥租金
- 点击标记/卡片 → 跳转行情页该资产，自动展开

### 3.2 技术实现
- 完全免费，无 API Key 依赖
- `map.invalidateSize()` 解决 iframe 半屏问题
- 地理定位优先使用浏览器 GPS，回退 IP 定位

---

## 四、互享页面

### 4.1 数据提报表单
- 项目名称 + 城市下拉（5城）+ 租金成交价（元/㎡）+ 免租条款多选
- 凭证上传（点击区域触发文件选择）+ 邮箱
- 提交后生成兑换码，数据审核后自动到账

---

## 五、我的页面（ProfilePanel）

### 5.1 免登录功能（始终可见）
- **分享转发获得查看额度**：裂变链接 + 一键邀约（复制链接）
- **激活兑换码**：输入6位码激活额度
- **商业付费直通车**：立即购买（99元/50次）/ 不限次包月（299元/月）

### 5.2 登录功能
- 邮箱 + 密码登录 / 注册（验证码流程）
- 微信快捷登录入口
- 关注微信公众号（PriceCRE）
- 账户统计：提交/购买/查看 计数

---

## 六、额度面板 (CreditPanel)

- 点击头部额度按钮弹出
- 显示邀约额度 + 付费额度 + 总额
- 绿色信用卡图标（点击切换眼睛图标）
- 点击外部自动关闭
- 底部按钮：提交数据 → 互享Tab / 购买额度 → 我的Tab

---

## 七、弹窗系统

### 7.1 Modal（居中弹窗）
- 半透明黑色遮罩 + 毛玻璃方框
- 仅"知道了"按钮，必须手动关闭
- 用于：指标解释、额度不足提示、购买成功/失败

### 7.2 Toast（快速提示）
- 底部滑入，2.5秒自动消失
- 用于：复制成功、兑换码激活等轻量提示

---

## 八、微信卡片生成 (WechatCard)

- 展开卡片后点击分享图标触发
- 生成包含以下内容的预览卡片：
  - PriceCRE 品牌 Logo + 名称
  - 项目名、城市、租金面价
  - 最多9项核心精算指标
  - QR 二维码（指向 pricecre.com）
  - "长按保存图片分享"提示
- 点击遮罩关闭

---

## 九、汉堡菜单 (HamburgerMenu)

- **城市/业态筛选**：全部/5城市 + 全部/3业态
- **快捷操作**：地图视图 / 互享兑换 / 个人中心（点击切换Tab）
- **底部**：服务条款/隐私政策/联系我们（带图标）+ 数据声明 + 狮帝芬链接(sz4ai.com)

## 十、全局特性

- **双主题**：Light/Dark CSS 变量切换
- **中英双语**：LanguageContext + 100+条翻译（Toggle按钮在Header）
- **移动端适配**：120%字号基准 + 禁止缩放 + 禁止水平拖拽
- **Footer**：© 2026 PriceCRE 商业地产量化精算资产终端

## 十一、数据模型

### 资产 (15条模拟数据)
- 5城市 × 3业态均匀分布
- 47项 DynamicIndicators（ESG已标准化为LEED/BREEAM/WELL）

### API路由
- `POST /api/auth/register` — 邮箱注册
- `POST /api/auth/verify` — 邮箱验证
- `POST /api/payment/test-buy` — 测试购买

### 状态管理
- 额度：local state (referral/purchased)
- 语言：LanguageContext
- Tab导航：CustomEvent 驱动
